Course Details

What Each Course Covers

Frontend Development

HTML/CSS/JS

Trains you to build interfaces people actually use.

This track covers structuring pages, styling layouts, and adding interactivity with JavaScript, building up to responsive, accessible websites you can deploy and show off in a portfolio.

What You'll Learn

  • Semantic HTML & responsive CSS layouts
  • JavaScript fundamentals & DOM manipulation
  • Version control with Git & GitHub
  • Building and deploying a portfolio project

Prerequisites

  • Basic computer literacy
  • No prior coding experience required
  • A laptop with internet access

Backend Development

Node.js

Trains you to build the systems that power applications.

This track covers servers, databases, and APIs, preparing you to build and connect the logic that sits behind the interfaces users interact with.

What You'll Learn

  • Server-side JavaScript with Node.js
  • Building REST APIs
  • Working with SQL & NoSQL databases
  • Authentication & deployment basics

Prerequisites

  • Basic JavaScript knowledge
  • Familiarity with command line, an added advantage

UI/UX Design

Figma

Trains you to design products people find easy to use.

This track covers research, wireframing, and prototyping, teaching you to turn ideas into interfaces that are both usable and visually considered.

What You'll Learn

  • User research & wireframing
  • Prototyping in Figma
  • Design systems & accessibility
  • Usability testing

Prerequisites

  • No design experience required
  • An eye for detail helps

Product Management

Strategy

Trains you to guide products from idea to launch.

This track covers prioritization, roadmapping, and cross-team communication, preparing you to translate user needs into product decisions.

What You'll Learn

  • Product discovery & user research
  • Roadmapping & prioritization frameworks
  • Working with engineering & design teams
  • Metrics & product analytics basics

Prerequisites

  • No prior experience required
  • Comfort communicating across teams

Data Analysis

SQL

Trains you to turn raw data into decisions.

This track covers spreadsheets, SQL, and visualization tools, building your ability to clean, analyze, and present data clearly.

What You'll Learn

  • Excel & spreadsheet modeling
  • SQL queries & database basics
  • Data visualization & dashboards
  • Presenting insights to stakeholders

Prerequisites

  • Basic math comfort
  • No coding experience required

Cybersecurity

Ethical Hacking

Trains you to protect digital assets.

This track covers ethical hacking, network security, and other cybersecurity topics, preparing you to identify and mitigate digital threats.

What You'll Learn

  • Ethical hacking techniques
  • Network security fundamentals
  • Incident response & forensics
  • Cybersecurity best practices

Prerequisites

  • No prior experience required
  • Comfort writing short-form content
